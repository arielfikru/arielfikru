# Hi, I'm Ariel 👋

Ariel Fikru Avicenna desu! \^w^/

I'm a self-proclaimed mad scientist who turns niche ideas into useful software. I build products and developer tools end to end, from backend systems and AI workflows to interfaces and the details that make them hold up in practice.

A lot of my ideas start with communities I care about, especially anime, cosplay, and the wonderfully specific corners of the internet.

## Things I've built

| Project | What it shows |
| --- | --- |
| [Anivora](https://github.com/arielfikru/anivora) | An anime-focused full-stack app with a React frontend, Hono API, authentication, and organization roles. |
| [Gib.run](https://github.com/arielfikru/gibrun) | A Go toolkit around Redis for data operations, counters, scanning, rate limiting, and migration. |
| [KULI](https://github.com/arielfikru/kuli) | A set of AI delegate CLIs with shared orchestration, voting, and health-aware fallback. |
| [hlsdrive](https://github.com/arielfikru/hlsdrive) | An HLS video storage and delivery research prototype, with a reusable library and measured browser findings. |
| [CSS animation skill](https://github.com/arielfikru/css-animation-skill) | A workflow for building React micro-animations in CSS, then recording and checking the actual motion. |
| [MonkeyType Indonesia archive](https://github.com/arielfikru/monkeytypeindo) | Daily leaderboard archiving, transparent recaps, and opt-in player profiles for a typing community. |

I also make smaller experiments when an idea won't leave me alone. [NekoTan](https://github.com/arielfikru/nekotan-release) is one of my earlier anime projects; [xflip](https://github.com/arielfikru/xflip) is an experimental two-sided image format.

If something here sparks an idea, [open an issue in the relevant repo](https://github.com/arielfikru?tab=repositories).
